# 📘 TrackWise – Task Management & Student Progress Tracking

**TrackWise** is a role-based task and progress management system designed for educators, mentors, and institutions to monitor student development, assign exercises, and track coding or practical work over time.

Built for efficiency and scalability, TrackWise integrates user portals, real-time dashboards, and progress analytics to simplify student tracking and task delegation.

---

## 🧠 Key Features

- 👨‍🏫 **Trainer Dashboard** – Assign, review, and monitor student tasks and attendance.
- 👨‍🎓 **Student Portal** – View assigned tasks, submit solutions, track progress.
- 🧩 **Role-Based Access** – Admin, Trainer, Student roles with dedicated interfaces.
- 🗃️ **Task Management** – Add deadlines, status updates, and progress logs.
- 📈 **Progress Analytics** – Visual charts and statistics for performance tracking.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, Chart.js
- **Backend:** Node.js, Express.js, MongoDB
- **Authentication:** JWT, Role-based access control

---

## 🌐 Use Cases

- 🏫 **Colleges & Bootcamps** – Monitor student coding & practical work progress
- 🧑‍🏫 **Mentorship Programs** – Assign weekly tasks and visualize learning patterns
- 📈 **Coding Clubs & Hackathon Teams** – Transparent task tracking and leaderboard
